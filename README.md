# Ароматека — учебный проект по практикам №8, №9 и №10

## Описание
Многостраничный адаптивный сайт-каталог парфюмерии. Проект знакомит посетителей с ароматическими семействами, нотами, стойкостью и шлейфом парфюмов, а также содержит форму подбора аромата и обратной связи.

## Технологии
- HTML5, семантическая структура;
- CSS3, CSS-переменные, Flexbox, Grid и именование классов по БЭМ-подходу;
- Bootstrap 5.3.8 (CDN): сетка и готовые компоненты;
- JavaScript: фильтрация каталога, проверка форм, показ сообщения/модального окна и закрытие мобильного меню после перехода;
- Git / GitHub.

## Страницы
- `index.html` — главная, hero-блок, преимущества, популярные ароматы;
- `catalog.html` — каталог парфюмов, адаптивная сетка карточек и фильтр по типу аромата;
- `product.html` — подробная карточка аромата, ноты, таблица характеристик и FAQ Accordion;
- `order.html` — форма подбора аромата и Bootstrap Modal;
- `contacts.html` — контакты, ссылки на социальные сети и форма обратной связи.

## Реализованные требования практик
### Практика №8
- Несколько связанных HTML-страниц, общая навигация и якорные ссылки.
- Семантические `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- Карточки, таблица характеристик, формы и модальное окно.
- Внешний CSS, переменные, состояния hover/focus, адаптивные Flexbox/Grid-блоки.
- Позиционирование элементов, включая sticky-шапку и бейджи.

### Практика №9
- Подключён Bootstrap CSS и JS Bundle через CDN.
- Используются `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `g-*`.
- Главная страница содержит hero-блок, преимущества, популярные карточки и footer.

### Практика №10
- Используются Bootstrap Navbar, Card, Button, Badge, Alert, Modal, Accordion.
- Формы используют `form-control`, `form-select`, `input-group`, `form-check`.
- Добавлены отдельные страницы каталога, описания аромата и заявки.

## Запуск
Откройте `index.html` в браузере. Для локального сервера можно использовать расширение Live Server в Visual Studio Code.

Bootstrap и шрифты подключаются через CDN, поэтому для их загрузки нужен интернет. Изображение hero-блока загружается с Unsplash; изображения флаконов карточек нарисованы средствами CSS.

## Проверка
1. Перейдите по всем пунктам навигации.
2. В каталоге выберите разные ароматические семейства.
3. Откройте страницу аромата и проверьте Accordion.
4. Отправьте пустую и корректно заполненную форму на страницах заявки и контактов: JavaScript проверит поля и покажет подтверждение. Данные пока не отправляются на сервер.
5. Проверьте мобильную навигацию и сетку через DevTools.

## Git: рекомендуемый порядок
```bash
git init
git add .
git commit -m "feat: create Aromateka Bootstrap perfume catalog"
git branch -M main
git remote add origin <URL-ВАШЕГО-РЕПОЗИТОРИЯ>
git push -u origin main
```

Для практики №10 можно создать ветку и Pull Request:
```bash
git switch -c feature/bootstrap-components
git add .
git commit -m "feat: add Bootstrap components pages"
git push -u origin feature/bootstrap-components
```
Затем на GitHub создайте Pull Request `feature/bootstrap-components` → `main`.
